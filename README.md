# 美超 · 慢半拍 · 使用手册

给 ChatGPT 的语音通话**加可调的延时**：可以让 AI 的声音晚几秒播出来，也可以让你说的话晚几秒发出去，两个方向互不影响，而且**加了延时还不会有回声**。

Windows / macOS 桌面应用。当前为测试版（beta）。

## 二、第一次打开会被系统拦一下（正常现象）

这个应用没有购买代码签名证书，所以第一次打开系统会拦截，**这不是病毒，按下面放行即可**：

- **Windows**：弹出「Windows 已保护你的电脑」→ 点左边的 **更多信息** → 点 **仍要运行**。
- **macOS**：提示「无法验证开发者」→ 打开 **系统设置 → 隐私与安全性**，往下拉找到那句提示，点 **仍要打开**。

## 三、登录 ChatGPT（重点看这里）

打开后就是一个 ChatGPT 窗口，**只需登录一次**，之后每次打开都还是登录状态。怎么登，取决于你平时用什么方式：

### 如果你用「谷歌账号」登录 ChatGPT —— 请用导入的方式

**不要在这个应用窗口里点谷歌登录。** 谷歌从 2023 年起**全面禁止**在这类内嵌窗口里完成登录，你点了只会看到「此浏览器或应用可能不安全」，走不通 —— 所以应用里干脆把谷歌登录入口藏起来了。

正确做法是**把浏览器里已经登好的状态同步过来**：

1. 先在你平时用的 **Chrome 浏览器**里正常登录 chatgpt.com（用谷歌账号登进去）。
2. **完全关掉 Chrome**（它开着会锁住登录数据）。
3. 回到本应用，按 `⌘,`（Windows 按 `Ctrl+,`）打开设置，在 **「登录」** 里点 **「⚡ 从本机 Chrome 导入登录」**。
4. 稍等几秒，页面会自动刷新成已登录状态，搞定。

> 用的是绿色版 / 便携版 Chrome，自动找不到？点旁边的「📁 手动选目录」，选到 Chrome 的 `User Data` 文件夹即可。

### 如果你用「邮箱密码 / 微软 / 苹果」登录

这些方式**在应用窗口里直接登就行**，没有任何限制，正常输账号密码即可。

## 四、怎么用延时

1. 在 ChatGPT 里**正常发起语音通话**。
2. 按 `⌘,` / `Ctrl+,` 打开设置，打开最上面的 **「启用探针」**。
3. 在 **「延时」** 里给「下行」（AI 说话）或「上行」（你说话）选一个秒数 —— 立刻生效，不用重新通话。
   - **快捷档位**：0～5 秒，点一下到位；再点一次已选中的档位就是归零（关掉这个方向）。
   - **滑块**：0.1 秒一档，最大 15 秒，需要精细值时用它。
   - 值就是开关：拖到 0 就是关闭这个方向。

关掉设置窗后，会变成一颗**悬浮球**，通话期间随时能调；鼠标移上去有总开关和上下行的快捷开关。

---

## 五、选麦克风 / 扬声器（可选）

设置页的 **「音频设备」** 里可以指定通话用哪个麦克风、哪个扬声器，不选就跟系统默认走。
**通话中也能切换**：扬声器立刻生效；麦克风会无缝切到新设备，不会断线。已自动过滤虚拟声卡。

## 六、更多说明

设置页**左上角的 `?`** 里有完整的图文使用指南（功能逐条介绍、回声怎么看、快捷键等）。

**快捷键：** `⌘,`/`Ctrl+,` 打开设置 · `⌘⇧D`/`Ctrl+Shift+D` 开关探针 · `⌘⇧B`/`Ctrl+Shift+B` 旁路（延时临时归零）· `F1` 打开使用指南。

## 七、出问题了

设置页 → **诊断** → **「日志文件」**，把打开的那个文件发回来即可。里面记了每一次开关、每一次延时改动和节点上的真实值，排查最快。
