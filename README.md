# 美超 · 慢半拍 · 使用手册

给 ChatGPT 的语音通话**加可调的延时**：可以让 AI 的声音晚几秒播出来，也可以让你说的话晚几秒发出去，两个方向互不影响，而且**加了延时还不会有回声**。

Windows / macOS 桌面应用。当前为测试版（beta）。

## 二、第一次打开会被系统拦一下（正常现象）

这个应用没有购买代码签名证书，所以第一次打开系统会拦截，**这不是病毒，按下面放行即可**：

- **Windows**：弹出「Windows 已保护你的电脑」→ 点左边的 **更多信息** → 点 **仍要运行**。
- **macOS**：提示「无法验证开发者」→ 打开 **系统设置 → 隐私与安全性**，往下拉找到那句提示，点 **仍要打开**。

## 三、登录 ChatGPT（重点看这里）

打开后就是一个 ChatGPT 窗口，**只需登录一次**，之后每次打开都还是登录状态。

### 用「谷歌账号」登录的 —— 请用导入的方式

**不要在这个应用窗口里点谷歌登录。** 谷歌**全面禁止**在这类内嵌窗口里完成登录，点了只会看到「此浏览器或应用可能不安全」—— 所以应用里干脆把谷歌登录入口藏起来了。正确做法是**把浏览器里已经登好的状态同步过来**：

1. 先在你平时用的 **Chrome 浏览器**里正常登录 chatgpt.com（用谷歌账号登进去）。
2. **完全关掉 Chrome**（它开着会锁住登录数据）。
3. 回到本应用，按 `⌘,`（Windows 按 `Ctrl+,`）打开设置，在 **「登录」** 里点 **「⚡ 从 Chrome 导入」**。
4. 稍等几秒，页面会自动刷新成已登录状态。

> 用的是绿色版 / 便携版 Chrome，自动找不到？点旁边的「📁 选目录」，选到 Chrome 的 `User Data` 文件夹即可。

### 用「邮箱密码 / 微软 / 苹果」登录的

**在应用窗口里直接登就行**，没有任何限制。

## 四、三步开始用

1. 按 `⌘,` / `Ctrl+,` 打开设置，点顶栏的 **🎙 话筒按钮**开始语音对话（也可以在网页里自己点）。
2. 看顶栏最右边的**探针按钮**是不是**绿色** —— 绿色就是开着。进入通话时它会自动打开。
3. 在 **「延时」** 里给 **↑ 上行**（绿色，你说的话）或 **↓ 下行**（蓝色，AI 说的话）选一个秒数 —— 立刻生效，不用重新通话。

关掉设置窗后，会变成一颗**悬浮球**，通话期间随时能调、随时能结束对话。

## 五、设置页顶栏

最常用的三个按钮固定在设置页最上面，往下翻也一直在。**按钮的颜色就是状态**，鼠标放上去会显示说明：

| 按钮 | 作用 |
| --- | --- |
| 🎙 **语音对话** | 白色 = 点一下开始语音对话；**红色停止键** = 正在通话，点一下结束。不用回网页里点 |
| ▭ **ChatGPT 窗口** | 点一下把 ChatGPT 窗口藏起来，只留设置和悬浮球，**通话在后台继续**；藏起来后变成黄色虚线框，再点显示 |
| 〜 **探针** | **绿色** = 开着，正在加延时；白色 = 关着，完全不介入通话 |

## 六、怎么设延时

| | 说明 |
| --- | --- |
| **↑ 上行 · 我说的话**（绿色，上面） | 延后发送你的声音 —— AI 会晚几秒才听到你 |
| **↓ 下行 · AI 说的话**（蓝色，下面） | 延后播放 AI 的声音 —— 你会晚几秒才听到 AI |
| 快捷档位 | 0 ~ 5 秒，0.5 秒一档，点一下到位；再点一次已选中的档位就是归零（关掉这个方向） |
| 滑块 | 0.1 秒一档，最大 15 秒 |

**值就是开关：拖到 0 就是关闭这个方向。**

> 想听出区别？在 AI **说话的时候**来回切 **↓ 下行** 的「关」和一个大一点的值（比如 5.0），差别非常明显。切 ↑ 上行时 AI 说话不会变 —— 上行管的是你发出去的声音。
>
> 延时卡片底部的 **「按住旁路」**：按住时两个方向临时归零，松开恢复。

## 七、悬浮球

设置窗一关它就出现，一直浮在所有窗口前面，可以拖到屏幕任何位置。

- **球面**：波形在流动 = 探针开着。下面两行是 ↑ 上行 / ↓ 下行当前的延时。
- **鼠标移上去**：展开面板 —— 第一行是**开始 / 结束语音对话**，下面是探针总开关和上下行快捷开关。
- **点一下球**：打开设置。

## 八、延时记录（图表 + Excel）

通话中**自动记录**每一段话的准确时刻（精度不到 1 毫秒），不用任何操作：

- **↑ 上行**：麦克风采集到你的声音 → 交给 ChatGPT 发送
- **↓ 下行**：AI 的声音到达本机 → 从扬声器播放

设置页 **「延时记录」** 里点 **📊 查看图表**，在应用里打开图表窗口，通话中实时刷新：

- **回复等待拆解**：你说完到听见 AI，多少是我们加的延时、多少是 ChatGPT 自己（网络、判断你说完、生成回答）；每一轮还标出「发出→听到」—— 从你的声音发出去到听见 AI 用了多久
- **时间线**：每段话在四个时刻上的位置
- **延时稳定性**：设定值和每段实测，点落在线上就是准

窗口里点 **导出**，会在「下载 / 美超慢半拍-延时记录」里存一份图表和一份 **Excel 表格**（概览 / 每段记录 / 对话轮次 / 按档位四张表，可以排序筛选、自己画图）。

> 上行和下行的段数**本来就不会一样多**（你连说几句 AI 才回一次、AI 分段回答、你插话）。能一一对上的是图表里的**对话轮次**。

## 九、选麦克风 / 扬声器（可选）

设置页的 **「音频设备」** 里可以指定通话用哪个麦克风、哪个扬声器，不选就跟系统默认走。

- **通话中也能切换**：扬声器立刻生效；麦克风无缝切到新设备，不会断线。
- 选过的设备这次**没连着**（比如蓝牙耳机关了），会自动改回系统默认，连上后重新选一下就行。
- 已自动过滤虚拟声卡。

## 十一、出问题了

| 情况 | 怎么办 |
| --- | --- |
| 完全没感觉 | 确认顶栏探针按钮是**绿色**，并且改的是对的方向（AI 的声音是 **↓ 下行**）。打开「延时记录」看看「测得」和「设定」是否一致 |
| 有回声 | 确认「回声」里的残留回声抑制开着；用耳机能根治 |
| 声音没从耳机出来 | 看「音频设备」里选的是不是这个耳机 |
| 语音按钮是灰的 | 没登录，或不在 ChatGPT 对话页 |
| 其它 | 设置页 → **诊断** → **「日志文件」**，把打开的那个文件发回来 |

> 测试阶段，发现任何问题都欢迎反馈。
